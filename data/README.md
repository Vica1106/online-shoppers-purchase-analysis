# Data provenance

`online_shoppers_intention.csv` is the unmodified CSV from the [UCI Online Shoppers Purchasing Intention Dataset](https://archive.ics.uci.edu/dataset/468/online), dataset ID 468. Downloaded 2026-11-14. UCI lists 12,330 sessions, 18 columns including `Revenue`, and no missing values.

Citation: Sakar, C. & Kastro, Y. (2018). *Online Shoppers Purchasing Intention Dataset*. UCI Machine Learning Repository. [https://doi.org/10.24432/C5F88Q](https://doi.org/10.24432/C5F88Q).
